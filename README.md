🌐 Host a Static Website with GitHub Pages

📌 Project Overview

This project demonstrates how to deploy a static website using GitHub Pages. It includes HTML, CSS, and optional JavaScript files hosted directly from a GitHub repository. The goal is to showcase free website hosting with version control and continuous updates.

🚀 Features

Free hosting using GitHub Pages

Simple static website structure

Version-controlled deployment

Easy updates with Git commits

Responsive design support

🛠️ Technologies Used

HTML5

CSS3

JavaScript (Optional)

Git & GitHub

📂 Project Structure
├── index.html
├── style.css
├── script.js (optional)
└── README.md

⚙️ Deployment Steps

Create a new repository on GitHub.

Upload your website files (index.html, CSS, JS).

Go to Settings → Pages.

Under Source, select:

Branch: main

Folder: / (root)

Click Save.

Your website will be live at:

https://your-username.github.io/repository-name/
